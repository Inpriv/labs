Features

Small on purpose. Comfortable on a phone.

Designed for ~40 columns first, then scaled up. Everything you can tap, you can also type.

⇄

Tap to swap

Soft keyboards have no Tab. The language chip is a tap target, so flipping direction is one touch.

▎

Card history

Every translation is a card. Tap one to copy it. Scroll back through the session with a swipe or PgUp.

↔

Never wraps

Long sentences scroll inside the input line instead of breaking the layout on a narrow screen.

⌕

Search-as-you-type picker

Choose a language by number, code (pl) or name (pol). Columns adapt to width.

$

Scriptable

trns hello world prints a card. Pipe it and you get only the translation.

◐

Accessible

Honours NO_COLOR, falls back to ASCII glyphs, and re-lays out live when you rotate your device.

Install

One command.

Paste it, open a new terminal, type trns. The installer checks for Python, verifies itself, and is safe to re-run to update.

curl -fsSL https://raw.githubusercontent.com/Inpriv/labs/trns/pwa/tools/trns/install.sh | bash

Then open a new terminal and run trns. On Termux, add pkg install termux-api for one-tap copy.

irm https://raw.githubusercontent.com/Inpriv/labs/trns/pwa/tools/trns/install.ps1 | iex

Run in PowerShell. No admin needed; installs to %LOCALAPPDATA%\trns and adds it to your user PATH. Needs Python 3.9+.

git clone https://github.com/Inpriv/labs.git
cd labs/tools/trns
python3 trns.py hello world      # one-shot
python3 trns.py                  # interactive

Run the tests with python -m unittest discover -s tests -t .

Privacy & honesty

Know where your text goes.

trns has no server of its own and keeps no history on disk.

  • Text is sent to Google’s public translate endpoint, and nowhere else.
  • That endpoint is unofficial: it can rate-limit or change without notice. Don’t send secrets.
  • Only a small config file is stored, at ~/.trns/config.json.
  • Standard library only, so the whole thing is a few hundred readable lines.
